# 装饰商务逐页设计计划

用于 create 的装饰商务设计；参考 [设计指南](../references/decorative-business-design.md)。
本文件是填写提纲，不是可直接提交的 task.json，也不替代 content、scene 和独立审核。

## 整册约束

- 受众、场景与页数依据：
- 核心叙事与内容来源；示例数据/未知项标记：
- 原创/参考改编/忠实重建边界；采用的机制与独立设计决定：
- 设计母题；字体层级；颜色角色；折痕、边距、连接与图片规则：
- 原生可编辑内容与允许的独立图片：
- 代表页及其用途：目标达成 / 时间线 / 问题改进 / 成果图文 / 风险或计划（按实际内容选择）
- `design.review_profile`：`decorative_business`

## 逐页填写（映射到 design.pages[].composition）

- 页 ID：
- `page_role`：cover / contents / section / body / closing
- 观众问题与本页核心信息：
- `claim_content_id`：本页已有内容 ID；body 必填
- `content_relation`：
- `layout_family`：按实际空间关系命名，不按图标或配色命名
- `reading_path`：按阅读顺序填写本页已有内容 ID
- `information_attachment`：inside_structure / along_path / paired_with_visual / mixed
- `layer_plan.primary`：结论与主结构如何呈现
- `layer_plan.secondary`：证据、分组、题签与连接如何承载内容
- `layer_plan.detail`：编号、单位、时间、短说明与来源如何安放
- `rationale`：构图如何表达内容；与相邻页面保持或改变什么，为什么
- 实现备注（不直接加入 composition）：非矩形文字安全区、精确数据图表、图片用途、未知项

## 关系选择提示（不是固定版式菜单）

| 内容关系 | 可考虑的组织方式 | 首先核对 |
| --- | --- | --- |
| 目标与实际 | 目标清单与对应序号、相接折翼 | 目标/实际/差距是否一一对应 |
| 阶段与进度 | 大结论配时间线、泳道、阶段门 | 时间区间、依赖与未完成项 |

| 协作与计划 | 汇流、交织、闭环、扇面或路径 | 输入输出、交接、验收或触发条件 |

## 合并与审核记录

- 作者交付：页面范围、内容 ID、来源版本/构建 ID、实际候选预览、未解决问题。
- 合并检查：预览对应合入版本；页面不是换图标但保持同一拓扑；必要系列页仍可比较。
- 逐页检查：主结论、数据口径、中文字体、说明归属、非矩形安全区、对比度与编辑能力。
- 独立整册 `deck_composition`：`status` 初始为 `revise`；填写真实 `observations` 与 `reviewed_page_ids`。
- 最终以实际 PPTX 渲染和目标软件编辑验证为准；不以对象数、空白率或构图种类计审美分。
