# PPT Smith v4.1.0 Beta 1 Release Readiness

## Verdict

This document describes the public Beta candidate on branch
`release/v4.1.0-beta.1`. It is not authorization to push, tag, publish, or
announce the release. Those external actions require a separate explicit step.

The candidate is acceptable for a controlled public Beta only when every check
in the final evidence table is green on the exact release commit.

## Scope of the claim

- Bespoke and Template are model-directed, run-specific production routes.
- Standard/Engineering is a diagnostic and compatibility route.
- Final status requires real rendering and the route's visual approval gate.
- The verified acceptance environment is macOS with LibreOffice; native
  Microsoft PowerPoint pixel parity is not claimed.

## Candidate evidence

The release commit must record:

- a clean worktree;
- consistent identity and version metadata;
- successful Skill entrypoint validation;
- pinned Python and Node runtime installation;
- full public test-suite results with no failures;
- a public-bundle audit with zero active errors and warnings;
- confirmation that no private PMO files or local run artifacts are present;
- a source archive hash and inventory;
- known skipped tests and their reasons.

## Known Beta limitations

1. Fourteen optional real-template integration tests require a non-public
   reference fixture; the public suite reports them as skipped when absent.
2. Two legacy template-extraction tests require a generated sample deck and may
   be skipped in a clean checkout.
3. Cross-template public tests use redistributable synthetic fixtures; further
   unseen real-template testing remains a GA requirement.
4. Bespoke and Template may require more than one render/review cycle.
5. Public Git history predating this release may still contain files removed
   from the Beta tree. A history purge, if required, is a separate destructive
   repository operation and is not performed by this closeout.

## GA exit criteria

- multiple unseen, redistributable real templates pass strict Template runs;
- native Microsoft PowerPoint open/readback smoke testing is recorded;
- Beta feedback confirms that the model/visual-review requirement is clear;
- plan-time visual-density prediction reduces avoidable first-render rework;
- no P0 packaging, privacy, license, identity, installation, or CI findings
  remain.
