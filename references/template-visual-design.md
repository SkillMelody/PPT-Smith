# 模板风格设计

只在用户提供模板/示例图且允许重新设计时读取。本指南使用现有 create 路线，
生图是可选设计阶段，不增加第四条主路线；不声称保留原 PPTX 母版。

## 先识别用户约束

- 保留公司母版、原生版式、图表或指定组件：template，编辑/克隆原生对象。
- 参考视觉风格、允许重排：create。可独立核验原生模板信息与实际渲染，登记 PNG/JPEG 风格参考。
- 完整设计图已批准且要求忠实重建：recreate。

`python3 -m engine design route --template --template-use style` 只表达已确认的使用意图，
不自动修改模板。严格模板不可静默降级为图片参考。create 的隔离执行器仍不接收 PPTX；
跨路线直接克隆原生组件尚未接入该执行器，不应宣称已保留原生母版或内嵌工作簿。

## 先确定整页设计

1. 看模板代表页，记录字体、字号层级、网格、留白、强调色、图表语言和页间节奏。
   提取原生资产信息辅助判断。仅配色相似不足以证明模板风格一致。
2. 从源文档锁定每页事实、单位、可见文案、图表数据及备注。每页有明确目的与阅读顺序。
3. 把风格规则和必须保持的品牌资产写进 design.brief；在 design.references 登记 style、
   page_ids、features、priority。模板示例中的业务数字不进入新内容。
4. 没有生图工具：制作原生设计，渲染 PNG 后观察与修订。模型不能识图时由独立视觉模型
   或人工承担必要审阅；不能填造看图记录。
5. 有生图工具且已获准使用：先探索少量代表页，再按选定方向扩展；图像中文字/数字需复核。
   提示中约束可编辑重建能力，优先清晰文字、平面图形和原生图表支持的形式。
   整页设计稿是视觉目标，不能作为覆盖整页的交付图片。Logo 使用原文件。

## 按页请求与目标冻结

```
python3 -m engine design image-request --task-dir "$TASK" --pages page-1,page-3
```

请求只含选中页可见内容与参考用途，不发送备注、来源原文或未选页。
请求含内容及风格上下文摘要，`generated: false`。宿主实际调用图片工具，
保存真实提示词和回执，将输出按 target 角色 ingest。
回执还须带 `request_sha256`，值为本次请求 JSON 的 canonical SHA256（UTF-8、键排序、
无空白分隔、不转义中文）；此摘要必须随实际调用记录，不能把旧图改签给新请求。多页分别生成、分别记录，
不得把程序预览登记为生图结果。调用前保存请求副本，避免后续请求覆盖。

确认设计符合内容、风格且能够重建后执行：

```
python3 -m engine design freeze-target --task-dir "$TASK" --page page-1 \
  --asset-id target-one --request-file image-request.json --confirmed-by actual-reviewer
```

这一步只登记宿主对设计方向的确认，独立成稿视觉审核仍然必需。
生成目标要求真实工具回执，目标绑定请求中的内容与风格上下文；内容或风格变化后会拒绝
旧目标。重新设计时同时清除该页旧 target_asset_id、target_kind、confirmed_by、
target_content_sha256、target_context_sha256，再生成新请求并登记新目标。
旧无版本锁任务保持兼容，但新生成目标应使用 freeze-target。

## 实现与审阅

文字/数字来自已核对的 content，图表来自真实数据，图片中的字形与像素高度都不是事实来源。
原生模板路线继续复用可用对象；create 重建设计的文字、形状、图表、表格，独立插画可保留为
可替换图片，明确其内部不可编辑。渐变、蒙版和字体嵌入等当前不支持的效果应在设计前约束。

原生饼图/环图可用 `label_colors` 为各扇区设置有对比度的数据标签，用
`label_number_format: '0"%"'` 显示原数据为 0–100 的百分数（不会修改数据）。
`legend_position` 支持 bottom/right，环图 `hole_size` 支持 10–90。
不要因默认标签颜色不可读就省略设计稿中的必要标注；实际渲染后检查。

分别评估设计稿质量与实际 PPT 的还原效果。查看清晰单页以及整稿总览，记录视觉重心、
阅读顺序、字体尺度、内容拥挤/空散、模板风格及页间节奏。单一证据页可简洁，不为数量
门槛凑卡片；复杂数据页必须保留必要标签、单位和口径。空白率和对象数用于定位问题，
不作为审美得分。真实渲染、数据/来源、编辑保存及独立审核合同保持生效。

## 成本比较

同源内容、同模板、同页数比较原生与生图后重建。记录实际调用次数、构建/修订次数、
工具提供的 token/费用和墙钟时间；没有 usage 时写 unavailable，不用字节代替。
把研发、模型审阅和首次生成成本分开，先做代表页，修订只带相关页上下文。
